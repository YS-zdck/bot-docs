# 消息类型

通过 `msg_type` 指定发送消息的格式。接收消息时，通过事件中的 `message_type`、`attachments` 等字段判断内容类型。

## 发送消息类型

| **msg_type** | **类型** | **内容字段** | **说明** |
| --- | --- | --- | --- |
| 0 | 文本 | `content` | 纯文本消息 |
| 2 | Markdown | `markdown` | 支持 Markdown 语法 |
| 3 | Ark | `ark` | 结构化卡片，需要申请对应权限 |
| 6 | 输入状态通知 | `input_notify` | 仅单聊支持，只展示“正在输入”状态 |
| 7 | 富媒体 | `media` | 图片、视频、语音或文件，需先获取 `file_info` |

发送时应根据 `msg_type` 填写对应的内容字段，不应同时填写互斥的其他内容字段。

## 接收消息类型

| **message_type** | **含义** | **说明** |
| --- | --- | --- |
| 0 | 普通文本 | `content` 携带文本内容 |
| 3 | 结构化卡片 | `ark_data` 携带卡片数据 |
| 103 | 引用消息 | `msg_elements` 携带嵌套内容 |

图片、视频、语音、文件等附加内容通过 `attachments` 携带，并通过 `content_type` 区分具体类型。

## 场景支持情况

| **类型** | **单聊** | **群聊** | **频道** |
| --- | --- | --- | --- |
| 文本 | 收发 | 收发 | 收发 |
| Markdown | 发送 | 收发 | 发送 |
| 图片 | 收发 | 收发 | 收发 |
| 视频 | 收发 | 收发 | 收发 |
| 语音 | 收发 | 收发 | 收发 |
| 文件 | 收发 | 收发 | 不支持 |
| 结构化卡片 | 接收 | 接收 | 不支持 |
| Embed | 不支持 | 不支持 | 发送 |
| 表情表态 | 不支持 | 不支持 | 收发 |
| 引用消息 | 接收 | 接收 | 接收 |

- 富媒体上传和发送流程详见[富媒体消息概述](../rich-media.md)。
- 表情表态仅频道支持，详见[表情表态](../trans/emoji.md)。
- 输入状态通知不是流式消息，不能更新消息正文。
