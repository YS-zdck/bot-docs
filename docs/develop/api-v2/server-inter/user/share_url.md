# 机器人链接

## 获取机器人资料页分享链接

### 功能描述

获取机器人分享链接，开发者可传入参数，用作追踪该链接后续被用户添加使用机器人的来源归因。

### 接口

```
POST /v2/generate_url_link
```

### 请求参数

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| callback_data | string(32) | 否 | 添加好友时会回传该参数给到开发者 |

### 返回参数

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| url | string | 生成的分享链接 |
