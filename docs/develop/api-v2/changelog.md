# 变更记录

## 20261028

### 新增

- **群聊 / 单聊消息**：新增图文卡片消息，支持在群聊和单聊场景下发送图文卡片（`msg_type=8`，`card` 字段）。

## 20261026

### 新增

- **群聊 @全部成员**：群聊场景的文本消息、markdown 消息支持使用 `<qqbot-at-everyone />` @全部成员，机器人需为该群管理员，且每个群每天仅可发送 1 次。

## 20261021

### 新增

- **[素材管理](./server-inter/message/material-management.md)**：支持将图片上传至平台，获取 `qqbot-media://` 引用后在 Markdown 消息中使用。

## 20261009


- **富媒体上传**（群聊 `/v2/groups/{group_openid}/files`、单聊 `/v2/users/{user_openid}/files`）：`raw_url` 说明细化为仅分片上传合并且 file_type 为图片/视频/语音时返回；错误码 `40093001` 描述修正为 BDH 通道异常；`40093002` 修正为超过今天。
- **全局自定义菜单**（`GET /v2/menu`、`PUT /v2/menu`）：移除 `MenuItem.align` 字段；Host 统一改为 `api.bot.qq.com`；补充 PUT 错误码 `40030008`、`40030013`、`40030014`、`40030016`、`40030020`。
- **群成员加入事件**（`GROUP_MEMBER_ADD`）：新增 `user_openid` 字段（跨应用统一标识，可能为空）；`timestamp` 标注为 Unix 秒。

## 20260916

### 优化

- **生成分享链接**（`/v2/generate_url_link`）：修正请求和响应字段说明。
- **消息事件**（群 @ 消息、群消息、单聊消息）：`ark_type` 枚举新增 `picture`（图片）取值说明。

## 20260903

### 新增

- **群管理接口**：新增群成员管理相关接口
  - 获取群成员列表
  - 获取群成员信息
  - 群成员批量移除
  - 群黑名单查询
  - 群黑名单操作

### 优化

- 修改了部分接口描述。

## 20260812

### 新增

- **自定义菜单**：新增查询、修改全局自定义菜单接口。
- **指令面板**：新增指令面板管理接口，支持查询列表、创建、查询详情、修改、删除及修改关联对象。

## 20260810

### 优化

- **接口调用域名统一**：所有接口调用域名统一为 `api.bot.qq.com`。

### 新增

- **群消息 / C2C 消息发送 Markdown 消息**：新增可选参数 `force_verify_image_resource`。开启后，当图片资源转存失败时，将中断消息发送并返回失败（默认关闭，保持原有行为）。
- **群管理接口**：新增群禁言管理相关接口
  - 查询用户禁言状态
  - 设置用户禁言
- **入群自动审批策略**：新增相关接口
- **入群申请审批**：新增相关接口
  - 拉取入群申请列表
  - 审批入群请求
- **事件**：新增用户入群申请事件。
